# progression_engine.md

## STRENGTH
- Increase load 2.5–5% if successful
- If failure twice → reduce load 5%

## HYPERTROPHY
- Increase reps before weight

## POWER
- Do not increase volume
- Increase intent/speed

## DELOAD
- Every 6–8 weeks OR
- Triggered by fatigue

---

## FATIGUE TRIGGERS
- Performance drop
- High RPE
- Inconsistent output

---

## RULE
Progress must be measurable:
- Load
- Reps
- Control

End.
