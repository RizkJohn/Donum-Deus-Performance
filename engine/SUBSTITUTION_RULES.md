# substitution_rules.md

## RULES
- Preserve movement pattern
- Preserve CNS load
- Preserve intent

---

## EXAMPLES

Trap Bar Deadlift →
- Barbell Deadlift

Pullups →
- Lat Pulldown

(The canonical machine list lives in `substitution_rules.md`; every pair there
preserves pattern and CNS exactly — e.g. DB RDL is Low-CNS so it substitutes
Single Leg RDL, not Trap Bar Deadlift.)

---

## RESTRICTIONS
- No compound → isolation downgrade
- No power → hypertrophy substitution

End.
